# Referência de controle para teste da integração

Esta referência sintética serve apenas para testar a ligação entre arquivo, chat e plano. Não descreve um ensaio realizado.

Adicionar uma etapa de estudo chamada **Estudar o controle PWM** dentro da execução do projeto. A etapa deve analisar o comando de um servo por PWM antes de qualquer montagem física. Ela deve continuar em rascunho e não contém observação, critério escrito pelo usuário ou especificação verificada de hardware.

O arquivo deve ficar relacionado a essa etapa como fonte de referência. Não é necessário criar um novo projeto nem substituir a árvore existente.
