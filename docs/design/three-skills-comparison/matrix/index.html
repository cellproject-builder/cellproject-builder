    Como interpretar o experimento
    Dentro de cada par, modelo, pedido, referências, contrato de saída e orçamento são iguais. A intervenção é o guia adaptado nas instruções de sistema. Os modelos são exibidos sem retoques no mesmo renderizador da aplicação.
    As duas vistas usam as mesmas luzes e orientação. O enquadramento automático centraliza cada cena e a ajusta ao espaço disponível, preservando as proporções internas de cada resultado.
    Quando há referência de imagem, os pixels do arquivo registrado são enviados ao modelo, além do texto do pedido. No contexto de especificações, o texto mostrado acima é enviado nas duas condições.
    O guia combina as skills comunitárias com regras e receitas próprias deste projeto. Este experimento não isola o texto upstream puro. Duas repetições permitem observar variação, mas não constituem validação estatística nem física.
    Neste conjunto, o ESP32 ativa o guia geral e uma receita específica de placa. O MG90S recebe o guia geral: o seletor atual não ativa a receita de microservo para esse pedido. Considere essa diferença ao comparar os dois objetos.
